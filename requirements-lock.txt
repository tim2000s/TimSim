# Two of these pins are load-bearing rather than incidental.
#
# pandas 3 returns datetime columns at microsecond resolution where pandas 2 returned
# nanoseconds. The DCLP3 loader converts through `datetime64[s]` so it is right either way,
# but an earlier version divided the integer view by a billion and collapsed 208-day traces
# into a few minutes without failing. If you move off this pin, run
# `pytest tests/test_validation.py -k dclp3` before believing anything.
#
# simglucose is pinned because it is the physiological model. It implements the 2008
# UVA/Padova release, and a change to its patient equations changes every result here.
# gym 0.9.4 is its own constraint, not one this package chose.
